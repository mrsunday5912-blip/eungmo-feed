처리하는 정보와 이용 목적

코어팩토리 주식회사는 이용자의 동의를 받아 다음 정보를 처리합니다.

  • 토스 앱 전용 사용자 식별 키, 내부 계정 번호, 로그인 세션 확인값, 계정 상태와 요청 횟수를 이용해 로그인, 계정 연결, 접근 권한과 부정 이용을 관리합니다.
  • 직접 입력한 닉네임을 계정 구분과 랭킹 표시에 사용합니다. 랭킹에는 닉네임, 순위, 모의 순손익, 수익률, 체결 건수가 공개될 수 있습니다.
  • 모의 시드와 잔고, 주문과 포지션, 체결, 모의 수수료와 손익 등 거래 기록을 저장해 거래를 처리하고, 내 기록, 시드 재도전, 랭킹을 제공합니다. 같은 거래 요청이 두 번 반영되지 않도록 요청 처리 기록을 보관합니다.

토스 로그인에서 이름, 전화번호, 이메일, CI(본인 확인에 쓰는 연결정보)는 받지 않습니다. 앱 시작 시 토스 SDK에서 읽는 익명 키는 앱 메모리에만 머물며 서비스 서버로 보내지 않습니다.

보관 장소와 처리 위탁

계정과 모의 거래 기록은 회사가 국내에서 직접 운영하는 서버(VM)의 전용 데이터베이스에 보관합니다.

토스 로그인은 주식회사 비바리퍼블리카가 제공하는 본인 확인 수단입니다. 광고 배너는 앱인토스 기능을 사용합니다.

회사는 서비스 접속 중계와 보안을 Cloudflare에 위탁합니다. 서비스에 접속할 때 HTTPS 요청이 Cloudflare Tunnel을 거치며, 접속 IP와 요청 정보가 중계 과정에서 국외에서 처리될 수 있습니다.

보관 기간과 삭제

계정과 모의 기록은 로그인 연결을 유지하는 동안 보관합니다. 이용자가 토스 앱에서 연결을 끊거나 로그인 동의를 철회하거나 토스에서 탈퇴하면, 토스 알림을 받은 뒤 세션을 종료하고 계정, 주문, 포지션, 체결, 잔고 변동, 시드 재도전, 요청 처리 기록과 랭킹 기록을 서비스 데이터베이스에서 바로 삭제합니다. 기존 랭킹 자료도 더 이상 표시되지 않도록 처리합니다.

동시에 들어온 로그인과 연결 해제 요청의 순서를 처리하는 데 쓰는 변환된 식별 확인값과 해제 시각은 마지막 처리 후 10분이 지나면 자동 삭제 대상이 됩니다. 로그인 유지에 쓰는 세션은 기본 12시간 후 만료됩니다.

법령에 따라 보관해야 하는 정보가 있다면 해당 기간 동안 따로 보관하고, 기간이 끝나면 삭제합니다.

운영 서버(VM)는 매일 백업합니다. 연결 해제로 운영 데이터베이스에서 지운 자료는 백업 보관 기간이 지나면 백업에서도 삭제합니다.
